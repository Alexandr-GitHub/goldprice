# Changelog

## 1.1.7-pl — 2026-09-14

- Режим наценок подгруппы `add_to_parent`: по умолчанию выключен (свои полные наценки и мин. маржа). Включён — дельты к родителю, мин. маржа от родителя. Миграция сохраняет прежнее поведение для существующих подгрупп.

## 1.1.6-pl — 2026-09-14

- Исправлен TypeError при удалении группы из контекстного меню (`record.get is not a function`).
- Контекстное меню групп: изменение и копирование через окно создания (корневая / подгруппа).
- Корзина: исправлена проверка `parent_id` при безвозвратном удалении.

## 1.1.5-pl — 2026-09-14

- Мягкое удаление весовых групп и подгрупп (`deleted_at`), вкладка CMP «Корзина»: восстановление и безвозвратное удаление.
- Создание корневых весовых групп из CMP. Удалённые группы исключены из пересчёта цен, шторма и списков в карточке товара.
- `gpQuotes`: в JSON добавлены `gold_usd`, `gold_usd2`, `stale`, `quote_stale`, `server_ts` — тикер унции на главной снова заполняется.
- Сниппеты `gpPrice`, `gpBuyoutForm`, `gpQuotes` в transport упакованы как `static=1` (код с диска, upgrade не затирает контракт).

## 1.1.4-pl — 2026-09-14

- Миграция `parent_id` в резолвере **namespace** (до копирования файлов).
- File vehicles: `preexisting_mode=REMOVE` — без `preserved.zip` (зависание на Beget).
- Исправлена fatal в tables resolver: функция миграции объявлялась после вызова.

## 1.1.3-pl — 2026-09-14

- Резолвер миграции `parent_id` ставится **до** vehicle assets: на апгрейде установка больше не зависает на `preserved.zip` до ALTER. Добавлен gate-тест порядка vehicles в zip.

## 1.1.2-pl — 2026-09-14

- Исправлена миграция `parent_id` при обновлении: в transport-пакете путь к резолверу таблиц указывал на старую папку `1.0.1`, из‑за чего ALTER не выполнялся. Резолвер усилен (идемпотентный ADD COLUMN + лог).

## 1.1.1-pl — 2026-09-14

- В пакет добавлена история изменений для установщика MODX (`changelog` в атрибутах transport).

## 1.1.0-pl — 2026-09-14

- Подгруппы ценообразования (серии монет): дельты наценок к весовой группе, CMP «Добавить подгруппу», фильтр цен по группе, комбо подгруппы в карточке товара.

## 1.0.1-pl — 2026-08-21

- Установка на чистый MODX: файлы компонента распаковываются до резолвера таблиц.
  В 1.0.0 резолвер шёл первым и не находил `core/components/goldprice/model`,
  из-за чего таблицы не создавались.

## 1.0.0-pl — 2026-08-21

- Котировки Profinance (золото и USD/RUB), пересчёт цен продажи и выкупа по весовым группам.
- Демпфер шага цены, режим «Шторм», вкладка «Ценообразование» в товаре miniShop2.
- Цена корзины только с сервера; позиция старше часа (`goldprice.cart_ttl`) удаляется.
- Цены на витрине — целые рубли. Ночной stale котировки не считается ошибкой cron.
- Заявки на выкуп, лимиты, письма менеджерам. CMP в разделе «Компоненты».
